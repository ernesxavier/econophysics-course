# Notas de repaso

Estas notas reúnen las herramientas matemáticas que usa el curso. **No hay
que leerlas de corrido**: la tabla de abajo dice qué repasar antes de cada
semana.

## Cómo están organizadas

Cada área tiene tres niveles, que corresponden a las rutas del curso:

| Nivel | Para qué sirve |
|---|---|
| **Básico (B)** | Lo necesario para la ruta básica: laboratorios y examen |
| **Intermedio (I)** | Lo necesario para leer las notas formales de cada sesión |
| **Avanzado (A)** | Lo necesario para la ruta avanzada |

Cada concepto tiene una clave: **área.nivel + número**. Por ejemplo,
**[P.I3](probabilidad.md#pi3)** es el tercer concepto intermedio de probabilidad (el teorema del
límite central). Las claves son enlaces: llevan directamente al concepto.
Cada área termina con un **autodiagnóstico** con respuestas.

| Clave | Área | Archivo |
|---|---|---|
| **P** | Probabilidad | [probabilidad.md](probabilidad.md) |
| **E** | Procesos estocásticos | [procesos_estocasticos.md](procesos_estocasticos.md) |

## Notación

Convenciones que se usan en todas las notas:

- $\hat\theta$ es el **estimador** de $\theta$ calculado con datos
  ($\hat\mu$, $\hat\sigma$, $\hat\alpha$).
- $\mathbb{E}[X]$ y $\langle X\rangle$ significan lo mismo, el valor esperado;
  la segunda es la notación habitual en física.
- $\bar F(x) = 1 - F(x) = \mathbb{P}(X > x)$ es la CCDF.
- $\sim$ tiene dos usos. $X \sim \mathcal N(0,1)$ dice que $X$ tiene
  distribución normal estándar; $f(x) \sim g(x)$ dice que $f$ y $g$ son
  asintóticamente iguales ([C.I6](calculo.md#ci6)). A la izquierda hay una
  variable aleatoria o una función, y eso los distingue.
- Vectores en minúscula ($x$, $v$), matrices en mayúscula ($A$, $C$);
  $\mathbf 1$ es el vector de unos y $A^\top$ la transpuesta.
- $\ln$ es el logaritmo natural (`log` en Julia).
- $\mathcal F_t$ es la información disponible al tiempo $t$.
- i.i.d.: independientes e idénticamente distribuidas.
- El nivel de significancia se escribe en porcentaje (5%), sin letra, para
  no confundirlo con el exponente $\alpha$.
